# DAFTAR (دَفْتَر) - REST API SPECIFICATION

**Version:** 1.0  
**Date:** 8 August 2026  
**Product:** Daftar  
**Base path:** `/api/v1`

## Conventions

Base path:

```text
/api/v1
```

Content type is `application/json` except PDF responses. Dates use `YYYY-MM-DD`. Timestamps use RFC 3339 UTC. Money and percentage inputs are decimal strings; calculated minor-unit values are returned as integers alongside formatted values where useful.

Protected endpoints require the authenticated session cookie. State-changing requests also require valid CSRF/origin protection.

## Standard response shapes

### Single resource

```json
{
  "data": {},
  "requestId": "req_01K..."
}
```

### Collection

```json
{
  "data": [],
  "page": {
    "nextCursor": null,
    "hasMore": false
  },
  "requestId": "req_01K..."
}
```

### Error

```json
{
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "One or more fields are invalid.",
    "details": {
      "fields": [
        {
          "path": "lineItems[0].quantity",
          "code": "INVALID_QUANTITY",
          "message": "Quantity must be a whole number greater than or equal to 1."
        }
      ]
    },
    "requestId": "req_01K..."
  }
}
```

## Authentication endpoints

### `POST /auth/register`

Public. Creates a user and authenticated session.

Request:

```json
{
  "email": "finance@example.com",
  "password": "strong password",
  "displayName": "Finance User"
}
```

Responses:

- `201` user profile; auth cookies set
- `409 EMAIL_ALREADY_REGISTERED`
- `422 VALIDATION_FAILED`
- `429 RATE_LIMITED`

### `POST /auth/login`

Public.

```json
{
  "email": "finance@example.com",
  "password": "strong password"
}
```

Responses:

- `200` profile; auth cookies set
- `401 INVALID_CREDENTIALS`
- `429 RATE_LIMITED`

### `POST /auth/refresh`

Uses refresh cookie and rotates the session.

- `200` new cookies
- `401 SESSION_EXPIRED`
- `401 SESSION_REUSE_DETECTED`

### `POST /auth/logout`

Protected. Revokes current refresh session and clears cookies.

- `204`

### `GET /me`

Protected.

Response `200`:

```json
{
  "data": {
    "id": "usr_...",
    "email": "finance@example.com",
    "displayName": "Finance User",
    "reportingTimezone": "UTC"
  },
  "requestId": "req_..."
}
```

## Document input model

```json
{
  "title": "August Software Services",
  "customer": "Acme Limited",
  "issueDate": "2026-08-08",
  "currency": "USD",
  "lineItems": [
    {
      "id": "required for an existing line; omit for a new line",
      "description": "Widget A",
      "quantity": 2,
      "unitPrice": "100.00",
      "discount": {
        "type": "percentage",
        "value": "10"
      },
      "taxRate": "5"
    }
  ]
}
```

For fixed discounts, `value` is a money string in document currency. For percentage discounts, it is a percentage string. Omit `discount` for none.

Line-item IDs are generated by the server. A client omits `id` when creating a line and preserves the server-returned `id` when submitting an existing draft line.

## Document endpoints

### `POST /documents`

Protected. Creates a draft, allocates a reference, calculates totals, and records an audit event.

Request: document input model.

Responses:

- `201` document
- `422 VALIDATION_FAILED`
- `422 MONETARY_OVERFLOW`

### `POST /documents/preview-calculation`

Protected. Calculates inputs without saving. Useful for a debounced frontend preview. Subject to strict rate and body limits.

Request: `currency` and `lineItems` from the input model.

Responses:

- `200` calculated lines, totals, and tax breakdown
- `422 VALIDATION_FAILED`

This endpoint never creates a reference, document, or audit event.

### `GET /documents`

Protected. Lists owned documents.

Query parameters:

```text
status=draft|finalized
currency=USD
from=2026-08-01
to=2026-08-31
sort=issue_date_desc
search=CrossVal
page=1
limit=20
archived=false
```

The implemented filters are `status`, `currency`, `from`, `to`, `page`,
`limit`, `archived`, and owner-scoped full-text `search`, with
`sort=issue_date_desc` as the supported ordering. Page numbers are positive
integers and reset to `1` when filters change.

Rules:

- Default limit 20; maximum 100.
- Default page 1.
- The take-home implementation defaults to `issue_date_desc`.
- Default excludes archived drafts.
- Search contains 2-100 characters and matches reference, title, or customer.
- The collection envelope returns `page.number`, `page.size`, `page.totalItems`,
  `page.totalPages`, and `page.hasMore`.
- Opaque cursor pagination and additional sort modes are future enhancements.

Responses:

- `200` collection
- `422 INVALID_FILTER`

### `GET /documents/{documentId}`

Protected. Retrieves one owned document.

- `200` document
- `404 RESOURCE_NOT_FOUND`

### `PATCH /documents/{documentId}`

Protected. Replaces editable draft fields and recalculates the document.

Headers:

```http
If-Match: "4"
```

Request: complete document input model. Using a complete editable representation avoids ambiguous partial line merging.

Responses:

- `200` updated document
- `404 RESOURCE_NOT_FOUND`
- `409 DOCUMENT_VERSION_CONFLICT`
- `409 DOCUMENT_FINALIZED`
- `409 DOCUMENT_ARCHIVED`
- `422 VALIDATION_FAILED`

### `POST /documents/{documentId}/line-items`

Protected. Adds a custom line to an active draft and recalculates the whole document.

Headers: `If-Match` required.

Request:

```json
{
  "description": "Consulting",
  "quantity": 1,
  "unitPrice": "200.00",
  "discount": { "type": "fixed", "value": "20.00" },
  "taxRate": "0"
}
```

Responses:

- `201` updated document, including the new server-assigned line ID
- `404 RESOURCE_NOT_FOUND`
- `409 DOCUMENT_VERSION_CONFLICT`
- `409 DOCUMENT_FINALIZED`
- `409 DOCUMENT_ARCHIVED`
- `422 VALIDATION_FAILED`

### `PATCH /documents/{documentId}/line-items/{lineItemId}`

Protected. Replaces editable inputs for one line and recalculates the whole document.

Headers: `If-Match` required.

Responses:

- `200` updated document
- `404 RESOURCE_NOT_FOUND` when the owned document or line does not exist
- `409 DOCUMENT_VERSION_CONFLICT`
- `409 DOCUMENT_FINALIZED`
- `409 DOCUMENT_ARCHIVED`
- `422 VALIDATION_FAILED`

### `DELETE /documents/{documentId}/line-items/{lineItemId}`

Protected. Removes one line from an active draft and recalculates the whole document. A draft may temporarily contain zero lines, but it cannot be finalized in that state.

Headers: `If-Match` required.

Responses:

- `200` updated document
- `404 RESOURCE_NOT_FOUND`
- `409 DOCUMENT_VERSION_CONFLICT`
- `409 DOCUMENT_FINALIZED`
- `409 DOCUMENT_ARCHIVED`

### `POST /documents/{documentId}/line-items/reorder`

Protected. Reorders all embedded line items without changing their raw
financial inputs or calculated totals.

Headers: `If-Match` required.

Request:

```json
{
  "lineItemIds": ["01K...", "01J..."]
}
```

The submitted IDs must be an exact permutation of the document's existing
line-item IDs: the same count, with no missing, unknown, or duplicate IDs.

Responses:

- `200` updated document
- `404 RESOURCE_NOT_FOUND`
- `409 DOCUMENT_VERSION_CONFLICT`
- `409 DOCUMENT_FINALIZED`
- `409 DOCUMENT_ARCHIVED`
- `422 INVALID_LINE_ORDER`

### `POST /documents/{documentId}/finalize`

Protected. Revalidates, recalculates, and permanently finalizes a draft.

Headers:

```http
If-Match: "4"
```

Responses:

- `200` finalized document
- `404 RESOURCE_NOT_FOUND`
- `409 DOCUMENT_VERSION_CONFLICT`
- `409 DOCUMENT_ALREADY_FINALIZED`
- `409 DOCUMENT_ARCHIVED`
- `422 DOCUMENT_REQUIRES_LINE`
- `422 VALIDATION_FAILED`

Persistent idempotency and replay handling are future production enhancements,
not requirements of the original CrossVal take-home.

### `POST /documents/{documentId}/duplicate`

Protected. Copies a finalized document's raw inputs into a new recalculated draft.

Optional request:

```json
{
  "issueDate": "2026-09-01",
  "title": "September Software Services"
}
```

Responses:

- `201` new draft
- `404 RESOURCE_NOT_FOUND`
- `409 SOURCE_DOCUMENT_NOT_FINALIZED`
- `422 VALIDATION_FAILED`

Persistent idempotency and replay handling are future production enhancements,
not requirements of the original CrossVal take-home.

### `DELETE /documents/{documentId}`

Protected. Satisfies draft deletion through a recoverable soft delete. It sets `archivedAt` rather than physically removing the record.

Headers: `If-Match` required.

- `200` archived draft
- `409 DOCUMENT_FINALIZED`
- `409 DOCUMENT_VERSION_CONFLICT`
- `404 RESOURCE_NOT_FOUND`

### `POST /documents/{documentId}/restore`

Protected. Restores an archived draft.

Headers: `If-Match` required.

- `200` active draft
- `409 DOCUMENT_NOT_ARCHIVED`
- `409 DOCUMENT_VERSION_CONFLICT`
- `404 RESOURCE_NOT_FOUND`

There is intentionally no destructive delete endpoint and no way to archive a finalized document.

### `GET /documents/{documentId}/pdf`

Protected. Generates a PDF from the owned stored record.

Optional query:

```text
disposition=inline|attachment
```

Responses:

- `200 application/pdf`
- `404 RESOURCE_NOT_FOUND`
- `503 PDF_GENERATION_FAILED`

Draft PDFs carry a `DRAFT` marker. The endpoint never accepts line or total input.

### `GET /documents/{documentId}/audit-events`

Protected. Lists the document's owned audit timeline.

Optional query: `limit` (`1` to `100`, default `25`). Events are returned newest
first. Cursor pagination is a future production enhancement.

- `200` audit collection
- `404 RESOURCE_NOT_FOUND`
- `422 INVALID_FILTER`

## Report endpoints

### `GET /reports/summary`

Protected. Aggregates finalized documents by issue date.

Query:

```text
from=2026-08-01
to=2026-08-31
```

Both dates are required and inclusive calendar dates. The original take-home
does not impose a maximum reporting range.

Response without a currency filter:

```json
{
  "data": {
    "from": "2026-08-01",
    "to": "2026-08-31",
    "documentCount": 3,
    "currencies": [
      {
        "currency": "USD",
        "documentCount": 2,
        "subtotal": "450.00",
        "totalDiscount": "40.00",
        "totalTax": "11.50",
        "grandTotal": "421.50",
        "taxBreakdown": [
          {
            "rate": "5",
            "taxableAmount": "230.00",
            "taxAmount": "11.50"
          }
        ]
      },
      {
        "currency": "AED",
        "documentCount": 1,
        "subtotal": "1000.00",
        "totalDiscount": "0.00",
        "totalTax": "50.00",
        "grandTotal": "1050.00",
        "taxBreakdown": []
      }
    ]
  },
  "requestId": "req_..."
}
```

Different currency totals are never combined.

The report uses stored server-calculated totals, includes finalized documents
only, and filters on `issueDate`. With no matching documents it returns
`documentCount: 0` and an empty `currencies` array.

### `GET /reports/timeline`

Protected. Returns finalized totals grouped by calendar month and currency.

Query: `from`, `to`, optional `currency`.

Response:

```json
{
  "data": {
    "series": [
      {
        "currency": "USD",
        "points": [
          {
            "month": "2026-08",
            "documentCount": 2,
            "grandTotal": "421.50",
            "tax": "11.50",
            "discount": "40.00"
          }
        ]
      }
    ]
  },
  "requestId": "req_..."
}
```

## Health endpoints

### `GET /health/live`

Public, minimal response. Confirms the process is running.

### `GET /health/ready`

Used by the deployment platform. Confirms required dependencies such as MongoDB are reachable. It must not disclose connection details.

## HTTP status policy

| Status | Use |
|---:|---|
| `200` | Successful read/update/action |
| `201` | Resource created |
| `204` | Successful action without body |
| `400` | Malformed request or missing protocol header |
| `401` | Missing/invalid authentication |
| `403` | Authenticated but blocked by a global policy; resource ownership still uses 404 |
| `404` | Owned resource not found or inaccessible |
| `409` | Lifecycle, version, uniqueness, or idempotency conflict |
| `422` | Semantically invalid input/calculation |
| `429` | Rate limit exceeded |
| `500` | Unexpected server failure |
| `503` | Required dependency or temporary generation failure |

## Global limits

- JSON request body: 1 MiB maximum.
- Title: 1-160 characters.
- Customer: 1-200 characters.
- Description: 1-500 characters.
- Lines per document: 200 maximum.
- Idempotency key: 16-128 safe characters.
- Search query: 2-100 characters.
- Page size: 1-100.

## API invariants

- No endpoint trusts submitted calculated values.
- Every business resource query is owner-scoped.
- Finalized documents have no mutation or deletion endpoint.
- Mutation requests use optimistic concurrency.
- Persistent idempotency/replay handling is a future production enhancement.
- Reports include finalized documents only.
- Different currencies are never added.
- Errors are specific, stable, and actionable.

## Future production enhancements

The following capabilities are deliberately outside the original CrossVal
multi-rate pricing calculator take-home scope:

- Persistent idempotency-key storage and successful-response replay.
- Opaque cursor pagination.
- Advanced document sorting beyond `issue_date_desc`.

They may be added for a production deployment without blocking evaluation of
the take-home document workflow.
